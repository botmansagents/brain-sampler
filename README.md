# brain-sampler

Free static sampler for the Real Estate Brain. No payments of any kind. Ready for GitHub Pages (serve from the repo root) but Pages is NOT turned on. Kevin approves before it goes live.

- Settings: `config.js` (search endpoint, open counties, Google Form link).
- Searches call the main site's free search endpoint for open counties only. If the endpoint is down or blocks cross-site calls, the page says searches are paused and points to the signup.
- Signup: mailto to support@botmansagents.com until a free Google Form link is pasted into `config.js`.
